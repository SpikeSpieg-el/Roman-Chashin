# Roman Chashin — ремесло × стрит × PS1 low-poly

Статичный адаптивный лендинг-выставка на русском языке с английским описанием проекта. Без сборщика, сторонних скриптов, аналитики, cookies и внешних запросов за шрифтами. Ссылки на Behance, VK и Telegram открываются только по клику. Выбор анимации сохраняется в localStorage, если браузер разрешает; аналитики и отслеживания нет.

## Что входит

- `index.html` — весь текст, семантические разделы, три постера «След», три слота Street Code, информация об авторе, контакты, FAQ, JSON-LD.
- `style.css` — адаптивная сетка, локальные шрифты, мобильная версия, reduced-motion.
- `script.js` — просмотр постеров в диалоге, стрелки, Escape, свайпы, копирование ссылки, мягкое появление блоков, наклон постеров, прогресс прокрутки и переключатель анимации.
- `assets/` — постеры WebP, уменьшенные варианты, OG-обложка 1200 × 630, favicon, локальные шрифты Onest и их лицензия OFL.
- `robots.txt` — разрешает обход. Не гарантирует индексацию.
- `configure.py` — привязка к реальному домену, canonical, абсолютные Open Graph URLs, идентификаторы Schema.org, XML sitemap с изображениями.

## Локальный просмотр

Откройте `index.html` в браузере. Либо из папки сайта:

```bash
python3 -m http.server 3000
```

Затем откройте `http://localhost:3000`.

## Публикация — важно для SEO

Домен не был предоставлен, поэтому фиктивного canonical и выдуманных адресов sitemap в исходниках нет. До публикации выполните:

```bash
python3 configure.py --url https://ВАШ-РЕАЛЬНЫЙ-ДОМЕН/
```

Замените адрес на свой публичный HTTPS-домен. Команда обновит `index.html`, добавит `sitemap.xml` и его адрес в `robots.txt`. Поддерживается путь к подпапке. Для сайта в подпапке директиву Sitemap нужно также добавить в robots.txt в корне домена.

Скопируйте на статический хостинг:

- `index.html`
- `style.css`
- `script.js`
- `assets/`
- `robots.txt`
- `sitemap.xml` (создаётся командой выше)

Python на хостинге не нужен. `README.md` и `configure.py` публиковать не требуется. Для предпросмотра хостинг может устанавливать `X-Robots-Tag: noindex`; на публичном домене этот заголовок необходимо убрать.

### После публикации

1. Проверьте ответ HTTP 200 для главной, изображений, robots.txt и sitemap.xml.
2. Настройте перенаправление HTTP → HTTPS и альтернативной версии www на выбранный адрес.
3. Подтвердите владение доменом в Google Search Console и Яндекс Вебмастере.
4. Отправьте sitemap.xml, затем главную страницу на переобход.
5. Добавьте ссылку на лендинг в собственный профиль Behance и другие реальные профили.
6. Проверьте canonical, OG-картинку и JSON-LD на опубликованном адресе.
7. Настройте кеширование статических ресурсов и Brotli/Gzip на стороне хостинга. При изменении файлов обновляйте версии или очищайте кеш.

Содержимое индексируется из исходного HTML, JavaScript для чтения страницы не нужен. Заголовки, описания и alt написаны естественным языком, без скрытого текста и повторяющихся ключей. Разметка включает Person, WebSite, CollectionPage, CreativeWorkSeries и VisualArtwork. Она помогает описать сущности, но не гарантирует расширенный сниппет, индексацию или позиции в поиске.

## Street Code — как вставить свои картинки

Серия размещена в блоке `#street`: скейтбординг, BMX и трюковые самокаты. Сейчас там честно обозначенные SVG-слоты, а не готовые спортивные работы. Три ранее присланных постера серии «След» сохранены.

### Простой способ (Python 3, без дополнительных библиотек)

Запускайте команды из папки сайта, заменив пути на свои:

```bash
python3 set-sport-image.py skate /путь/к/скейт.jpg
python3 set-sport-image.py bmx /путь/к/bmx.webp
python3 set-sport-image.py scooter /путь/к/самокат.png
python3 package.py
```

Скрипт копирует картинку в `assets`, обновляет нужную карточку и alt, убирает подпись «ВИЗУАЛ СКОРО». Поддерживаются JPG, PNG и WebP. Картинка показывается целиком, без обрезки. Рекомендуемая ориентация — вертикальная; размер около 900–1400 пикселей по ширине, желательно до 500 КБ для быстрой загрузки. Сжатие скрипт не выполняет.

`package.py` пересобирает `Roman-Chashin.html` и `Roman-Chashin-site.zip` рядом с папкой сайта. На хостинге обновите `index.html` и добавленные файлы `assets`. При настроенном домене повторно запустите `configure.py --url ...`, чтобы добавить новые изображения в sitemap, затем `package.py`.

### Вручную, без Python

В `index.html` найдите `data-sport="skate"`, `data-sport="bmx"` или `data-sport="scooter"`. В соответствующем `<img>` замените `src` на путь к своей картинке из `assets`, уточните `alt`. Удалите соседний `<figcaption class="slot-status">…</figcaption>`. Никакого сборщика для сайта не требуется.

## Анимация

- Поочерёдное появление строк заголовка и мягкий reveal блоков при прокрутке.
- Медленное вращение wireframe-куба, плавная бегущая строка.
- Наклон постеров не более 1,5° по каждой оси, только при точном указателе мыши.
- Небольшой подъём контактных карточек и прогресс прокрутки.
- Плавающая кнопка отключает декоративное движение. При `prefers-reduced-motion: reduce` анимация выключается автоматически.
- Нет захвата скролла, мигания, звука, автопрокрутки или тяжёлой WebGL-сцены.
- Без JavaScript весь текст, изображения, ссылки, FAQ и контакты доступны; анимация выключена, постеры открываются по прямой ссылке.


## Логотип CHASHIN — low-poly геометрия

Геометрия и палитра взяты из загруженного HTML-референса по выбору пользователя. На сайте используется CHASHIN; название исходного шаблона, чужие контакты и фиктивные реквизиты не перенесены.

10 модулей на плане 4 × 4u, высота 1.2u, изометрические оси 30°. Каждый модуль представлен верхним и двумя боковыми четырёхугольниками. Всего 30 полигонов в исходной SVG-сборке, включая перекрытые поверхности. При разбиении каждой грани пополам — 60 треугольников до оптимизации. Цвета: #FF7A44 / #E04A15 / #BC340C.

Визуальная связь с PS1 и low-poly — простая геометрия, крупные плоскости и плоский цвет, а не утверждение об использовании оригинального игрового движка.

В `#identity` работают «Знак / Построение» и «Повтор». Анимации адаптированы из референса: сборка с шагом 70 мс, длительностью 720 мс и прорисовка каркаса через stroke-dashoffset. Запуск при появлении блока, переключении режима и нажатии повтора. Знак рядом с PS1 собирается на старте и при наведении мыши.

Общая кнопка движения и prefers-reduced-motion отключают анимации, включая уже запущенные. Без JavaScript готовый знак и тексты уже есть в HTML. Выставка, Street Code и контакты сохранены.

`brand-geometry.py` в исходниках сайта — генератор SVG (Python 3, стандартная библиотека). Формула: x'=(x-y)·cos(30°)·100, y'=((x+y)/2-z)·100. Генератор обновляет файлы SVG и favicon; встроенные SVG-демонстрации в index.html — статический снимок, при изменении конструкции их необходимо обновлять отдельно.

Не переносились CDN, внешние шрифты, фотографии и неверные размерные подписи из шаблона. Вектор масштабируется без потери резкости, но на 16 px части могут сближаться; рекомендуемый размер для ясного чтения — 24–32 px и больше. Проверка товарного знака не проводилась.
